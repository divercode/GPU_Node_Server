## 二、软件说明书

### 1. 软件用途

本软件面向**两台自用 GPU 服务器**的小规模算力平台，提供：

- GPU 温度、功耗、利用率、显存、XID/ECC 等监控视图；
- Slurm 作业列表、作业详情、GPU 作业关联；
- 告警中心、告警规则、告警处置；
- 按用户/课题组的 GPU·h 资源用量统计（不做费用结算）；
- 用户、课题组、审计日志、系统组件状态；
- 基于 OIDC 的身份认证与按角色/数据范围的后端鉴权；
- 容器化网关、后端、身份代理和静态前端的部署形态。

### 2. 软件组成

| 模块 | 技术 | 主要职责 |
|---|---|---|
| 前端 SPA | 原生 HTML/CSS/JS、SVG 图表 | 工作台、资源目录、作业、监控、告警、用量、管理页面 |
| 平台后端 | Python 3.12 标准库 HTTP 服务 | 身份映射、RBAC、对象级权限、API、采集上报、审计 |
| 网关 | Nginx | 8080 单入口、静态托管、auth_request、API 反向代理、身份头注入 |
| 身份链路 | Dex + oauth2-proxy | OIDC 登录、会话、组/角色传递 |
| 采集 agent | Python + nvidia-smi | GPU 指标采集与上报 |
| 部署 | Docker Compose | gateway/backend/oauth2-proxy/dex 编排，仅暴露 8080 |

### 3. 主要技术特点

1. **单入口认证**：浏览器只访问 8080，由网关统一完成 OIDC 会话校验，后端只信任带共享密钥的代理身份头。
2. **服务层 RBAC**：角色由 LDAP/Dex 组映射；普通用户仅能查询本人作业/本组用量，全局 GPU/节点/审计需运维或管理员权限。
3. **GPU-作业关联**：后端把 DCGM/agent 指标与 Slurm 作业映射关联，前端展示作业维度的 GPU 曲线。
4. **数据范围控制**：前端菜单隐藏只是体验层，授权在后端 API 完成。
5. **轻量容器化**：后端零第三方依赖；网关/后端非 root、只读根文件系统；仅发布 8080。
6. **CSRF 防护**：写接口使用 HttpOnly CSRF cookie + `X-CSRF-Token` 双提交校验，并校验同源 Origin。
7. **轮询刷新**：前端在安全页面按 15s 轮询刷新，避免打断抽屉/弹窗/输入操作。

### 4. 运行流程

1. 用户浏览器访问 `http://<内网IP>:8080/`；
2. 未登录时由网关重定向到 Dex 登录；
3. 登录成功后 oauth2-proxy 建立会话；
4. 网关在校验会话后，将用户/组身份头注入到 `/api/v1/*` 请求；
5. 后端完成角色映射、对象级校验并返回 JSON；
6. 前端根据 `/api/v1/me` 渲染菜单和数据，写操作携带 CSRF token；
7. GPU 服务器 agent 通过采集 token 上报 GPU 指标。
