# 专利检索与补充材料清单

> 申请前请专利代理师按本清单做检索；以下关键词和对比文件只是起点，不构成检索结论。

## 1. 检索数据库

- CNIPA 专利检索及分析系统；
- Google Patents；
- Espacenet；
- WIPO PATENTSCOPE；
- IEEE/ACM/arXiv 论文（GPU 故障处置、告警关联）；
- 开源项目文档（DCGM exporter、Slurm、Prometheus Alertmanager、Dex、oauth2-proxy）。

## 2. 关键词

### 故障隔离

- 中文：GPU 故障、XID、ECC、节点 drain、GPU 隔离、作业映射、Slurm、DCGM、自动隔离、故障处置；
- 英文：GPU fault isolation、XID error、ECC DBE、Slurm drain、job mapping、GPU quarantine、DCGM、prolog mapping。

### 告警联动

- 中文：告警关联、事件图、根因分析、影响面、告警抑制、自动处置、恢复验证、GPU 集群；
- 英文：alert correlation、event graph、root cause analysis、impact analysis、alert suppression、auto remediation、GPU cluster。

### 身份与权限

- 中文：OIDC 反向代理、身份头、RBAC、对象级权限、CSRF、GPU 平台；
- 英文：OIDC reverse proxy、identity header、RBAC、object-level authorization、CSRF、GPU platform。

## 3. 需要重点对比的现有技术

1. DCGM exporter 的 `--hpc-job-mapping-dir` 与 `hpc_job` 标签；
2. Slurm `scontrol update NodeName=... State=DRAIN` 与自动 drain 脚本；
3. Prometheus Alertmanager 的分组、抑制、静默；
4. 现有 AI 运维平台的告警关联/根因分析专利；
5. OOD + Dex + Apache `mod_auth_openidc` 的身份头传递；
6. Nginx `auth_request` + oauth2-proxy 的代理认证。

## 4. 必须补充的实验/实施例

- 真实 2 节点/16 卡环境，XID/ECC/温度/功耗故障注入；
- 双源映射缺失/冲突场景；
- 自动隔离与人工处置的时延、误隔离率、资源损失对比；
- 告警合并前后数量、根因准确率；
- 恢复验证窗口和误恢复率；
- 审计记录完整性。

## 5. 公开与保密

- 申请前不要公开演示、发论文、上传公开仓库；
- 如已公开，评估是否适用 6 个月宽限期（中国仅限特定情形，需律师判断）；
- 与参与开发/运维人员签署发明人/保密协议。

## 6. 权属

- 确认著作权人/申请人：单位还是个人；
- 确认发明人名单及贡献；
- 如使用开源代码，确认许可证义务和专利许可条款；
- 如委托开发，确认合同中的知识产权归属。
