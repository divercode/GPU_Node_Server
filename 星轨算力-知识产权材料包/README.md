# 知识产权材料包（草案）

本目录是根据当前「星轨算力 GPU Cloud Console」原型整理的**软件著作权登记材料**和**发明专利技术交底书/权利要求草案**。

> 重要说明
> 1. 以下均为技术与申请文件草案，**不构成法律意见**，不能保证授权。
> 2. 申请前必须做专利检索、补充真实实验数据，并由专利代理师审核改写。
> 3. 公开演示、发论文、上传公开仓库前先申请，避免丧失新颖性。
> 4. 开源组件（Slurm、OOD、Dex、Nginx 等）的许可证合规需单独审查；本材料只针对自研部分。

## 建议申请顺序

1. **先做专利检索**：确认“故障隔离”“告警联动”的具体技术特征没有被现有专利/论文公开。
2. **先申请发明专利**（或至少先递交技术交底书），再做公开演示。
3. **同步登记软件著作权**：代码和用户手册分别准备鉴别材料。
4. 需要品牌保护时再考虑商标；界面可考虑 GUI 外观设计。

## 技术主题一句话

- 故障隔离：**把 GPU 级硬件错误通过“双源作业映射 + 映射置信度 + 分级隔离 + 恢复验证”闭环，落到 Slurm 节点/GPU 隔离动作。**
- 告警联动：**把告警、GPU、作业、节点、账号构建成事件图，去重/定根因/算影响面，再由策略引擎执行确认、通知、drain、工单和恢复验证。**
