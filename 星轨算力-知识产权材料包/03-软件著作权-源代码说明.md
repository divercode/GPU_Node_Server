# 软件著作权·源代码鉴别材料说明

## 1. 材料范围

本材料从当前可运行原型中提取原创源程序，包含：

- 后端 Python：`backend/app.py`、`backend/auth.py`、`backend/agent.py`
- 前端：`frontend/index.html`、`frontend/js/*.js`、`frontend/js/pages/*.js`、`frontend/css/*.css`
- 网关：`gateway/nginx.conf`、`gateway/portal.conf.template`、`gateway/entrypoint.sh`
- 部署：`docker-compose.yml`、`backend/Dockerfile`、`gateway/Dockerfile`

合计原始代码约 **6,254 行**；为控制 Word 自动换行导致页数漂移，生成时将超长行按 150 字符折行，共 **6,681 行、134 页**。按中国版权保护中心要求，提交**前 30 页 + 后 30 页**，共 60 页；本材料包已生成 `星轨算力-源代码-前30页后30页.docx`/`.pdf`。

## 2. 已排除的敏感内容

- `.env` 中的全部部署密钥；
- `backend/auth_users.json` 中的密码哈希；
- `dex/config.yaml.tmpl` 中的密码哈希；
- 测试 cookie、临时脚本、运行日志；
- `frontend/preview` 截图资源。

## 3. 页眉页脚

- 页眉：`星轨算力GPU集群监控与作业管理平台软件 V1.0`
- 页脚：第 X 页 / 共 60 页
- 字体：Consolas（西文）/ 宋体（中文），8pt
- 每页 50 行，保留文件路径分隔行，便于审查代码连续性

## 4. 生成方法

材料包提供 `ip/build_soft_code_doc.py`，可重新生成：

```powershell
python ip/build_soft_code_doc.py
```

脚本会按文件顺序拼接代码，生成前 30 页和后 30 页，并自动写页眉、页脚和页码。
